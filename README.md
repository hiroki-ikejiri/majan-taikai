# 麻雀大会スコア

麻雀大会のスコア入力・集計をスマホで楽にする Web アプリです。主催者が大会を作って URL を共有すると、参加者はログインなしで参加できます。

## できること

| 場面 | 内容 |
|---|---|
| 大会作成 | 「今回の大会は何人？」から始めて、名前（手入力・テキストファイル・マークダウンの表・過去の参加者）とルールを設定。名前は改行・読点・カンマ・引用符・かっこなど、区切り方は自由（名前の中の空白では分けない）。名前が足りない分は「ゲスト1、ゲスト2…」で埋められる（あとで設定から本名に直せる。過去の参加者には残らない） |
| 共有 | 参加者用 URL と QR コード。参加者は名前をタップするだけ（端末に記憶） |
| 卓割り | 予選は同じ人となるべく当たらないよう自動。決勝は予選の成績順（上位 4 人が A 卓） |
| 結果入力 | 卓の誰か（トップの人）が東南西北の順に素点を入力すると、ポイントを自動計算。3 人分を入れると残り 1 人の点数は自動で入る（手で上書きも可）。合計 10 万点チェックと二重入力防止つき |
| 順位 | ホームに自分の順位・トップとの差・決勝ラインまでの差。全体順位には決勝ラインの帯 |
| 精算 | 主催者が場代、各自がチップ枚数を入力すると支払い額が確定。金額を隠すボタンつき |
| 主催者 | 結果の修正・削除、ルールや名前の変更（ポイントは再計算）、決勝卓の確定、精算の確定 |

## 計算ルール

- ポイントは（素点 − 返し）÷ 1000 を百の位で五捨六入し、ウマを足し、トップにオカを足す
- マイナスは絶対値で丸める（−17.5 → −17）
- 合計が必ず 0 になるよう、1 位は「2〜4 位の合計のマイナス」で決める
- 同点は起家（東）に近い方が上
- 精算額は「合計ポイント × レート ＋ チップ枚数 × 単価 − 場代 ÷ 人数（100 円単位で切り上げ）」

## 構成

| 役割 | 使っているもの |
|---|---|
| 画面 | 素の HTML / CSS / JavaScript（ビルド不要）。`public/` |
| データ・ログイン | Firebase（Firestore・Authentication）。権限は `firestore.rules` |
| 公開 | Cloudflare Pages。`main` への push で GitHub Actions が自動デプロイ |

URL に `?demo` を付けると **デモモード** で動きます（例 `http://localhost:5173/?demo`）。データはそのブラウザの中だけに保存されるので、本番のデータに触らずに画面を確認できます。E2E テストも必ずデモモードで動きます。`public/js/config.js` を `null` にした場合もデモモードになります。

```
public/
  index.html
  css/style.css
  js/
    app.js            画面の切り替えとデータの購読
    derive.js         今の回戦・順位など画面に出す値の組み立て
    logic/            計算ロジック（ポイント・卓割り・順位・精算・名前読み込み）
    store/            データの保存先（firebase.js / demo.js）
    views/            画面（主催者・参加者・主催者メニュー・素点入力）
tests/                単体テスト（node:test）
e2e/                  画面操作テスト（Playwright、デモモード）
firestore.rules       Firestore の権限ルール
docs/SETUP.md         本番セットアップ手順
```

## 開発

手元で動かす。

```bash
npm start
```

ブラウザで `http://localhost:5173/?demo` を開きます（`?demo` を外すと本番の Firebase につながります）。

テストを実行する。

```bash
npm install
```

```bash
npx playwright install chromium
```

```bash
npm run test:all
```
